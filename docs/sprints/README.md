# sprints/ — agile schema & workflow

Backfilled 2026-06-23. Structure follows the koni-docs standard.

```
sprints/
├── README.md              ← this file
├── STATUS.md              ← AUTO-GENERATED kanban (RULE-5 — never hand-edit)
├── epics/EPIC-N.md        ← epic = contract between PRD FRs and stories
├── stories/US-X.Y-*.md    ← canonical task source (AC + Tasks live here)
└── sprint-YYYY-WNN.md     ← one file per one-week window
```

## Conventions

- **Story id** `US-X.Y` matches the filename prefix and a PRD `Epics & User Stories`
  entry (RULE-6). `X` = epic number.
- **Status** flows `backlog → ready → in-progress → review → done`. `version_shipped`
  is mandatory when `done` (bare semver, RULE-16).
- **AC + Tasks** live inside the story file, never in the sprint file.
- **STATUS.md** is regenerated by `koni-docs status` (RULE-5).
