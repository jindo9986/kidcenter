## Goal

Define one distinctive, documented visual language so every app looks considered and
consistent, and so UI reviews have a source of truth to check against.

## Background

`apps/portfolio/DESIGN.md` documents Editorial Warm: Fraunces (display) + Be Vietnam Pro
(body), indigo brand + medal-gold accent, cream background, comfortable density. Applied
to the portfolio code and later adopted by family + study. Materializes AD-4.
